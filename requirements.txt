# Dependencies for the deployed Flask backend (backend/my_flask_app/).
#
# Railpack builds from the repo ROOT and installs from THIS file. It copies
# only requirements.txt into the image before running "pip install" (Docker
# layer caching), then copies the rest of the source. So this file must be
# SELF-CONTAINED: an "-r backend/my_flask_app/requirements.txt" include fails
# because that path is not in the image yet at install time.
#
# Mirror of backend/my_flask_app/requirements.txt (the canonical dev list),
# with two server-appropriate changes:
#   * opencv-python-headless replaces opencv-python (no system libGL on the
#     server; identical cv2 API minus the GUI calls, which we do not use)
#   * pytest omitted (test-only)
# The start command is in the root Procfile: gunicorn --chdir backend/my_flask_app.
# The old torch/ultralytics pip-freeze that used to be here is in git history.
